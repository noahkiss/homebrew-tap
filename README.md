# Homebrew Tap

Custom Homebrew formulas.

## Installation

```bash
brew tap noahkiss/tap
```

## Available Formulas

### basic-memory

Local-first work-tracking and knowledge CLI (`bm`), a hard fork of basic-memory.

```bash
brew install noahkiss/tap/basic-memory
```

### notify-mcp

MCP server that sends push notifications via Apprise.

```bash
brew install noahkiss/tap/notify-mcp
```

After installation:
```bash
notify-mcp init
```
